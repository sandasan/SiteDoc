# SiteDoc

Минимальное расширение Chrome для локальной офлайн-библиотеки веб-страниц. Оно сохраняет очищенный текст открытой страницы, позволяет собрать его в коллекцию с вложенным оглавлением и экспортировать коллекцию в EPUB 3 или печатать в PDF.

## Установка для разработки

1. Откройте `chrome://extensions`.
2. Включите «Режим разработчика».
3. Нажмите «Загрузить распакованное расширение» и выберите эту папку.
4. Закрепите SiteDoc на панели, откройте обычную страницу сайта и нажмите значок расширения.
5. В панели выберите библиотеку или нажмите «＋», чтобы создать новую. Созданная библиотека сразу станет активной для сохранения страниц.
6. Откройте библиотеку, чтобы настроить содержание и экспортировать её.

PDF создаётся через системный диалог печати Chrome — выберите «Сохранить как PDF». EPUB скачивается как файл `.epub`.

## Текущие ограничения

- Данные хранятся в `chrome.storage.local` профиля Chrome; это локальная библиотека одного браузерного профиля.
- Сохраняются HTML основной области, доступные браузеру CSS-правила, заголовки страницы, исходный адрес и изображения до 2 МБ на страницу. EPUB упаковывает сохранённые изображения и строит оглавление по коллекции и заголовкам. PDF включает страницу содержания, исходный HTML и доступные стили сайта. Интерактивность не архивируется; ресурсы с ограниченным CORS и веб-шрифты могут остаться внешними ссылками.
- Отдельную страницу можно добавлять или обновлять; дубли определяются по адресу без якоря. Хлебные крошки автоматически создают узлы-разделы и размещают страницу в подходящем месте дерева.
- Кнопка «Найти страницы раздела» сначала ищет текущую страницу в дереве меню сайта и предлагает соседние страницы из того же уровня/группы; если навигация не распознана, используется папка URL. Перед загрузкой показывается список до 30 страниц с родительским разделом. Пользователь может снять лишние флажки; выбранные страницы загружаются с того же сайта, дубли обновляются по одному общему подтверждению. Для таких страниц сохраняются текст, изображения и стили, доступные same-origin/CORS.
- Вложенность вручную назначается кнопкой ↳, порядок меняется стрелками.
- Сбор раздела загружает HTML без выполнения JavaScript страницы; контент, который подгружается только после запуска скриптов или прокрутки, может отсутствовать.
- Страницы Chrome Web Store, `chrome://` и некоторые защищённые страницы не доступны расширению.
