# SiteDoc

Минимальное расширение Chrome для локальной офлайн-библиотеки веб-страниц. Оно сохраняет очищенный текст открытой страницы, позволяет собрать его в коллекцию с вложенным оглавлением и экспортировать коллекцию в EPUB 3 или печатать в PDF.

## Установка для разработки

1. Откройте `chrome://extensions`.
2. Включите «Режим разработчика».
3. Нажмите «Загрузить распакованное расширение» и выберите эту папку.
4. Закрепите SiteDoc на панели, откройте обычную страницу сайта и нажмите значок расширения.
5. В панели выберите библиотеку или нажмите «＋», чтобы создать новую. Созданная библиотека сразу станет активной для сохранения страниц. В панели также можно удалить все библиотеки вместе с их страницами.
6. Откройте библиотеку, чтобы переименовать или удалить выбранную коллекцию, настроить содержание, отметить несколько страниц для удаления и экспортировать её.

PDF создаётся через системный диалог печати Chrome — выберите «Сохранить как PDF». EPUB скачивается как файл `.epub`.

## Текущие ограничения

- Данные хранятся в `chrome.storage.local` профиля Chrome; это локальная библиотека одного браузерного профиля.
- Сохраняются HTML основной области, доступные браузеру CSS-правила, заголовки страницы, исходный адрес и доступные изображения, включая ленивые изображения и CSS-фоны. Загрузка изображений и CSS-ресурсов выполняется service worker расширения, чтобы поддерживать ресурсы на сторонних доменах; для этого Chrome запрашивает у пользователя доступ ко всем сайтам. Ограничения сайта, недоступные авторизации и физические ограничения браузера/диска могут помешать полному сохранению. Для ресурсов нет встроенных ограничений по размеру, количеству или времени загрузки; одиночное сохранение обрабатывает их небольшими параллельными партиями, а импорт раздела — последовательно. EPUB упаковывает сохранённые изображения и строит оглавление по коллекции и заголовкам. PDF включает страницу содержания, исходный HTML и доступные стили сайта. Интерактивность не архивируется.
- Отдельную страницу можно добавлять или обновлять; дубли определяются по адресу без якоря. Иерархия разделов определяется по хлебным крошкам и меню сайта; сегменты URL используются как резервный путь и для добавления явно указанной версии документации. Совпадающие разделы автоматически объединяются.
- Кнопка «Обнаружить все разделы» собирает ссылки из видимого дерева меню документации. Поиск текущего раздела строит дерево по дочерним пунктам активного узла меню; если сайт не показывает такое дерево, используются прямые ссылки из основного содержимого стартовой страницы. Повторяющиеся URL объединяются, а ссылки на произвольные страницы из текста дочерних страниц не запускают обход всего домена. Перед добавлением показывается дерево найденных страниц с уровнями и флажками; можно выбрать целый подраздел или отдельные страницы. Запросы идут последовательно с паузой не менее секунды; если сервер отвечает HTTP 401, 403, 429 или 503, сбор останавливается и не пытается обходить ограничение. Дубли обновляются по одному общему подтверждению. Для страниц сохраняются текст, изображения и стили, доступные через разрешения расширения.
- Вложенность вручную назначается кнопкой ↳, порядок меняется стрелками.
- Сбор раздела загружает HTML без выполнения JavaScript страницы; контент, который подгружается только после запуска скриптов или прокрутки, может отсутствовать.
- Страницы Chrome Web Store, `chrome://` и некоторые защищённые страницы не доступны расширению.
